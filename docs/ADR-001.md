# ADR-001: FitFlow Technology Stack

**Status:** Accepted

## Context
FitFlow needs iOS, Android and web clients; AI-personalized workouts; low-friction
nutrition logging; social/realtime features; progress tracking; and strong privacy/security.

## Decision
Use Flutter + NestJS + FastAPI + PostgreSQL + Redis + Cognito + S3 on AWS.

## Rationale
- Flutter: cross-platform iOS/Android/web.
- NestJS: structured TypeScript API and realtime gateway.
- FastAPI: Python ML/model-serving service.
- PostgreSQL: relational integrity and JSONB flexibility.
- Redis: low-latency cache and event distribution.
- Cognito: managed identity and JWT/OIDC.
- S3: private scalable object storage.

## Consequences
More initial complexity than a simple MVP, but clear separation of concerns and
independent scaling of API, AI and data workloads.

## Compliance note
HIPAA/GDPR compliance is not automatic. It depends on the complete system design,
configuration, legal basis, contracts, policies, operational controls and jurisdiction.
