# Technology Comparison – FitFlow

## Frontend
Flutter is recommended because FitFlow requires a seamless iOS/Android/web experience.
React Native is a strong alternative, Kotlin Multiplatform is attractive when native
control is prioritised, and SwiftUI is excellent for Apple-only development but does
not satisfy the full cross-platform requirement.

## Backend
- NestJS: primary API and realtime gateway
- FastAPI: AI/ML microservice
- Go: optional future specialist service

## Database
PostgreSQL is recommended because FitFlow has strongly related entities and needs
relational integrity, strong queries and JSONB flexibility.

## Authentication
Amazon Cognito is recommended because it integrates with the AWS architecture and
provides managed identity, JWT/OIDC and authorization capabilities.

## Weighted frontend result
- Flutter: 4.75/5
- React Native: 4.55/5
- Kotlin Multiplatform/Compose: 4.00/5
- Swift/SwiftUI: 3.00/5
